# Security Policy

## Supported Versions

We provide security updates for the latest released version of **Fill Your Menubar**.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy leak in Fill Your Menubar:

1. **Do not create a public issue.**
2. Send an email describing the issue to **jedieason@gmail.com**.
3. Include detailed steps to reproduce the vulnerability, along with relevant logs or environment details.
4. We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a timeline for a coordinated disclosure and fix.
